# Growth Coach

> Your personal cognitive growth coach — 4 thinking modes + metacognition monitoring

[English](#english) | [中文](#中文)

## English

### What is this?

A growth coaching skill with **4 thinking modes** that automatically switch based on your state:

| Mode | Icon | When to use |
|------|------|-------------|
| Mentor | 🎓 | Confused, seeking advice or knowledge |
| Red Team | 🔴 | Just made a decision, need stress testing |
| Action Designer | 🎯 | Know what to do, need to start |
| Deep Review | 🔄 | Have results, need to reflect |

### Key Features

#### Automatic Mode Switching
The coach detects your state from your words and automatically switches to the right mode.

#### Metacognition Monitoring
- Detects when you're overusing one mode (e.g., always asking, never testing)
- Reminds you to balance thinking styles
- Tracks cognitive weaknesses and avoidance patterns

#### Growth Log
Every session is logged with:
- Mode used and transitions
- Key insights (what YOU discovered)
- Cognitive weaknesses identified
- Emotional trajectory
- Action items

#### Self-Evolution
The coach improves itself:
- Logs what worked and what didn't
- Suggests improvements to its own prompts
- Auto-applies fixes when possible

### Installation

```bash
git clone https://github.com/beyond06120925/growth-coach.git
cp -r growth-coach ~/.claude/skills/growth-coach
```

### Usage

- "I'm feeling lost about my career" → **Mentor mode**
- "I just decided to pivot my startup" → **Red Team mode**
- "Help me start implementing this plan" → **Action Designer mode**
- "Let me reflect on what happened this week" → **Deep Review mode**
- "Check my growth status" → **Metacognition report**
